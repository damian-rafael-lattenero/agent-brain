# B19 · Parametricity

**Denotes.** Theorems for free: a signature's type parameters promise blindness — the body cannot inspect what `T` is — and from that blindness alone, behavior is provable before the body exists.

## 1 · The aha

`fun <T> pick(flag: Boolean, a: T, b: T): T` has exactly two honest bodies. The type leaves no room for a third: `T` carries no operations, so nothing can peek. The signature is a partial proof — and the moment the body casts or reflects, the promise is broken and the honesty must move into the signature (`T : HasName`).

## 2 · What it denotes

In Haskell (Wadler, *Theorems for free!*): parametricity is a language guarantee — pure code cannot inspect a fully parametric type, so `id :: a -> a` IS the identity, provably. Every polymorphic signature constrains its own implementations.

## 3 · In your languages

**Kotlin.** Generics erase — `T` can be met with `is` and reflection at runtime, so parametricity is a DISCIPLINE: the review reads generic signatures as promises and treats casts inside as betrayal. The constrained form (`T : HasName`) is the honest move when inspection is real. Full row: `kotlin-kb/notes/canon-map.md`, `parametricity`.

**Nushell.** The weakest form anywhere: `any` is an open door, a `closure` says nothing — signature honesty is the whole discipline (concrete types wherever the shape is known, the typing check keeping the annotations). Full row: `nushell-kb/notes/canon-map.md`.
