# A2 · How they talk to each other: who talks to whom

**Denotes.** There are only two directions in the system — a call, where one side waits for the other, and an event, where one side appends a line and leaves — and every arrow in the map is one of the two.

## 1 · The aha

A call needs both sides alive at the same moment. A bus does not: the producer appends one line and is free, the consumer reads it later. That single difference is why the bot can record a finished exchange while the brain is down.

## 2 · What it denotes

Two shapes. Synchronous: a client calls a server and waits for a response. Asynchronous: a producer appends an event to a topic and a consumer reads it whenever it can. The wire is append-only, every line carries a unique id, and delivery is at-least-once — so the consumer, not the producer, must deduplicate.

In Haskell the call is `IO a` inside a route; the asynchronous side is a fold over an endless list of events: the producer is a write, the consumer is a fold.

## 3 · In your languages

Kotlin: the taxonomy is a type. `BusKind` in `agent-brain/core/src/main/kotlin/dev/lattenero/brain/bus/BusEvent.kt` is a closed enum, so an unknown kind fails the decode at the edge and no later code can see an off-taxonomy event.

Nushell: the same wire is a text file, and `record-lines` in `Scripts/lib/json-lines.nu` drops every line that is not a record — because `from json` is lenient and would otherwise hand you a bare string.

The difference: the type refuses at the edge, the script filters at the edge. The snag: both must deduplicate, because the same event can arrive twice and nothing inside the line says which copy is the copy.

## 4 · In your system

Who talks to whom, as a list of arrows:

- The bot appends: `bot/src/zcode_bot/bus.py` writes one JSON line per event to `~/.zcode/agent-brain/bus-events.jsonl`, and a failed write is counted, never raised into the exchange it was recording.
- Its taps append too: `bot/src/zcode_bot/hooks.py` publishes the prompt and the completion of a Mac exchange as separate events of one id.
- The brain reads: `agent-brain/core/src/main/kotlin/dev/lattenero/brain/bus/FileTailer.kt` follows that file, or `agent-brain/core/src/main/kotlin/dev/lattenero/brain/bus/Kafka.kt` consumes the topic, and both hand batches to one ingest.
- The store is the join point: `agent-brain/core/src/main/sqldelight/dev/lattenero/brain/db/sq/BusEvents.sq` inserts by id and ignores a duplicate, so a replay leaves the table identical.
- Two consumers read that table: the memory worker takes the unprocessed completions, and the cost projection turns each of them into a row.
- The other direction is a call: `bot/src/zcode_bot/brain_client.py` asks the brain over HTTP and waits for the answer.

## 6 · Drill

Prove the law: append the last line a second time and watch the table refuse the copy.

```nu
let f = '~/.zcode/agent-brain/bus-events.jsonl' | path expand
let q = 'select count(*) from bus_events'
let n0 = (^docker exec agent-brain-pg psql -U brain -d agent_brain -Atc $q)
((open --raw $f | lines | last) + "\n") | save --append $f
^/Users/lattenero/Projects/agent-brain/core/build/install/agent-brain/bin/agent-brain ingest --once | ignore
let n1 = (^docker exec agent-brain-pg psql -U brain -d agent_brain -Atc $q)
[$n0 $n1]
```

Green when the two numbers are equal. The failing case it rules out: a consumer that trusts the wire and writes every line it sees, which double-counts every replay.

## 8 · Close-out

- Denotes: two directions, one append-only wire, and a consumer that owns the duplicates.
- Lives: `bot/src/zcode_bot/bus.py`, `agent-brain/core/src/main/kotlin/dev/lattenero/brain/bus/FileTailer.kt`, `agent-brain/core/src/main/sqldelight/dev/lattenero/brain/db/sq/BusEvents.sq`.

Checkpoint: the drill prints the same count twice.

## Minimum path

- **The aha**: a call waits, an event does not — the wire is the part that survives one side being down.
- **The signature**: `publish(event) -> Line`, `consume(lines) -> Events`.
- **The checkpoint**: the duplicate line appended by hand does not raise the row count.
