# N11 · `log.nu` — the voice of a script

**Denotes.** The receipt voice: one function that speaks to stdout AND the run log, so what the user saw survives the terminal that ran it.

## 1 · The aha

Every fleet script used to choose: print the line (gone when the terminal closes) or log it (invisible while it runs). The receipt needs BOTH, from ONE call, so the two never drift: what the user sees on stdout is appended — with its newline — to the script's own `~/Library/Logs/<name>.log`. The honest-indicators law at the process edge: the spoken line IS the record.

## 2 · What it denotes

`emit-to` (log path, line): print to stdout and append to the log in one call. Verified: `emit-to /tmp/u20-log.txt 'the receipt line'` prints the line and the file carries it — the run's receipt outlives its terminal. One function, because a script that logs through two doors eventually shows the user one thing and records another.
