# B20 · IO and effects at the edge

**Denotes.** Effects live at the edges — the core computes on values, the boundary converts ONCE — and a channel that looks like an error but is control flow (cancellation) never gets folded into a value. The measured #5 violated concept in the fleet.

## 1 · The aha

`runCatching` over a suspend call reads as "be safe" and means "be lost": CancellationException is a `Throwable`, so the safe-looking net swallows the signal that says the caller gave up — and the rescue leg keeps running in a dead scope. The four channels exist so that safety and control flow never wearing the same clothes.

## 2 · What it denotes

In Haskell, effects are types: `IO a` says "this computes in the world", and failure enters as a value — `try` answers `Either SomeException a` at ONE edge, and the core folds Eithers. Nothing downstream can be surprised by a throw, because nothing downstream sees one.

Kotlin's coroutines hide a second channel inside the exception type: cancellation travels AS an exception but MEANS control flow. The taxonomy (`fp-kb/notes/kotlin-error-taxonomy.md`) names the four channels — typed value, throw (bugs only), cancellation (rethrown always), border convert (once, known case only).

## 3 · In your languages

**Kotlin.** The ladder: the CancellationException arm rethrown FIRST, then the narrow arm, then the edge conversion (`kap catching`/`settled` — the operators already do the dance). `runCatching` never wraps a suspend call; pure parse conversions are the honest exception — `runCatching { json.parse(...) }` over CPU code cannot launder a cancellation because there is nothing to cancel mid-parse. Full row: `kotlin-kb/notes/canon-map.md`, `io-effects-edge`.

**Nushell.** The edge answers a RECORD: every external run gets `complete` (`{stdout, stderr, exit_code}`), and the script decides on the exit code as a value — nothing ignored, nothing swallowed. The gap is absent by construction: no cancellation channel exists for jobs to launder. Full row: `nushell-kb/notes/canon-map.md`.
