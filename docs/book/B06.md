# B06 · Sum and product types

**Denotes.** A sum type is a closed set of alternatives — exactly one branch holds — and a product type is values that only exist together. Together they are the shape that makes invalid states unrepresentable, and the measured #1 violated concept in the owner's Kotlin fleet.

## 1 · The aha

A collection of strings named KINDS is a taxonomy written in the least safe encoding: any string compiles, so any typo compiles. The same taxonomy as an enum with a total parse: any wire lands SOMEWHERE, typos included, and the type checker proves the dispatch covers every branch.

## 2 · What it denotes

In Haskell: `data Priority = Low | Normal | High | Unknown` — the constructors are the only inhabitants, the parse is total (Unknown is the degraded constructor that keeps totality), and dispatch is a function of one clause per constructor, coverage checked by the type checker.

The closed set is the point: no call site can add a branch the dispatcher never saw. That is what a `Set<String>` vocabulary can never give — the set and its dispatcher live apart, so nothing proves they agree.

## 3 · In your languages

**Kotlin.** A sum with payloads is a `sealed interface` with `data class`/`data object` branches; a payload-free taxonomy is an `enum class`; a wire vocabulary rides the enum with a `wire` property and a total parse — `byWire ?: degraded`, never `enumValueOf` (it throws on unknown wires). Dispatch is an exhaustive `when` with NO `else` — an `else` silently kills the type checker's coverage proof. Full row: `kotlin-kb/notes/canon-map.md`, `sum-product-types`.

**Nushell.** No sum types, so the tagged record: `{tag: 'ok', value: ..., error: null} | {tag: 'unknown', ...}` — a uniform shape where the tag decides, type-aliased and law-tested in `nushell-fp/mods/types.nu`. Parse once at the boundary into the tag. Full row: `nushell-kb/notes/canon-map.md`.
