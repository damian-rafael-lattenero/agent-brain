# B22 · Laws as properties

**Denotes.** A law of an abstraction written as a Bool-valued function that a machine checks on generated inputs — being lawful becomes a fact, not a hope.

## 1 · The aha

"Doesn't mean that it's a monad, it just means that it was made an instance of a type class" (LYAH): the type checker checks shapes, not behavior. The Typeclassopedia's instance that typechecks and violates the identity law is the hole — and one property run closes it.

## 2 · What it denotes

In Haskell: `quickCheck :: Testable prop => prop -> IO ()` (wiwinwlh) — generate, check, falsify. Three honest boundaries: laws between functions run POINTWISE at generated arguments (never comparing functions); 100 cases of bounded size are support, not proof; a law that hangs fails with TIMEOUT, not forever.

## 3 · In your languages

**Kotlin.** No QuickCheck — the fleet encodes it: seeded `generateSequence` cases + pointwise checks; kap's laws (LAWS.md) are green exactly this way (Kotest properties), and kap-kotest ships parameterised suites: `backpressureLaws(producer, items).verify()`. Full row: `kotlin-kb/notes/canon-map.md`, `laws-as-properties`.

**Nushell.** prop.nu's `for-all`: seeded generators (nushell's random is NOT seedable), shrink-lite on failure, tagged outcomes. Full row: `nushell-kb/notes/canon-map.md`.
