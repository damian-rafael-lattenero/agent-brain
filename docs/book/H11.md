# H11 · Exponential and cartesian closed category: a function as an object

**Denotes.** An exponential is an object standing for the arrows between two objects; a cartesian closed category has a terminal object, all products and all exponentials — so that a function is a value like any other.

## 1 · The aha

B03 made functions first-class; H11 names the object that makes it lawful: `b^a`, with evaluation as the counit of the product-with-`a` adjunction from H05. "Currying is essentially built into the syntax of Haskell" because the object is there.

## 2 · What it denotes

The pattern: one arrow `g : z × a → b`, and a unique `h : z → (a ⇒ b)` for every `g` — the correspondence IS currying, `h` "the curried version of `g`". The exponential `b^a` is "the function object, or the internal hom-object between two objects"; evaluation `(a ⇒ b) × a → b` is the counit.

A cartesian closed category is "1. The terminal object, 2. A product of any pair of objects, and 3. An exponential for any pair of objects" — and such categories "provide models for the simply typed lambda calculus". In Haskell, `curry` and `uncurry` are the two moves, and a function may take and return functions.

The approximation: a function is code, not a table — "eager memoization of functions from those types would require infinite storage" — and the mirrored manuals have no text on exponentials; the `CCC` class is the manual's own sketch. The trap: `a -> b -> c` is a function taking an `a` and RETURNING a function `b -> c` — "that's why we can call a function as `f x y` or as `(f x) y`". Full theory: `theory-kb/notes/category-theory/exponential-ccc.md`.

## 3 · In your languages

**Kotlin.** No curried functions in the pages read; functions are values with a receiver — `run`, `with` and `apply` "reference the context object as a lambda receiver - by keyword `this`" — and the docs admit scope functions "don't introduce any new technical capabilities": the function-as-value is there, the exponent object is informal. Full row: `kotlin-kb/notes/canon-map.md`, `first-class-functions`.

**Nushell.** The closure is the function-as-value: "an anonymous function, often called a lambda function, which accepts parameters and closes over (i.e., uses) variables from outside its scope", written `{|args| expressions }` and passed "as parameters to iteration style commands like `each`, `where`, and `reduce`". Full row: `nushell-kb/notes/canon-map.md`, `first-class-functions`.
