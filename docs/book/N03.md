# N03 · `combinators.nu` — the small verbs that compose

**Denotes.** The classic higher-order functions over first-class closures — identity, constant, composition, flip — proving that nushell closures ARE values.

## 1 · The aha

The whole module is four tiny functions, and that is the point: nushell closures are stored in variables, passed as arguments and returned from other closures (verified live on 0.117). No auto-currying exists, so composition is explicit — `(compose f g) x` is `g (f x)`, right-to-left like Haskell's `.`.

## 2 · What it denotes

`identity` (the neutral element of composition), `konst` (a closure that always yields `x` — the constant factory), `compose` (right-to-left), `flip` (swap the first two arguments). Verified: `compose {|x| $x + 1 } {|x| $x * 2 }` applied to `3` answers `8` — the increment ran FIRST, composition is right-to-left.

## 3 · In your languages

**Nushell.** This module; four verbs, no wrapping of builtins (the gaps-only law).

**Kotlin.** The same four exist as one-liners: `{ it }`, `{ x -> _ }`, `f.andThen(g)` / `f.compose(g)`, method references. Kotlin needs no library here — the honest reading of the gaps-only law: nushell-fp fills a real gap, Kotlin's stdlib already has the shapes.
