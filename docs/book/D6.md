# D6 · The oracle: compiling is the truth

**Denotes.** The compiler — not the model's confidence — decides whether a write worked; an oracle runs it right after the write and speaks the failure while the cause is still on screen.

## 1 · The aha

A gate refuses before the action; an oracle answers after it. PostToolUse cannot block — so the oracle does not try: it compiles the file the agent just wrote and hands the errors back as context, seconds after the write, while the intent is still warm. The refusal classes stay with the gates; the truth speaks here.

## 2 · What it denotes

`oracle : File -> Verdict` with `Verdict = spoke errors | clean | timeout | error`, advisory by construction: exit 0 always, the errors ride as a note, every run lands one row in the count file. Two laws make it trustworthy: the TIME CAP (gradle 45 s, ghc 20 s — a cap is said, not hidden), and the COOLDOWN (one judgment per file per window — an Edit-Write pair costs one compile, and a crashed leg never consumes the judgment).

The measured facts of today's fleet: Bash is 53% of all tool calls, Edit 17%, Write 12% — the oracle therefore hooks the Edit/Write boundary, where a failing compile costs one step, not a deploy.

## 3 · In your languages

Kotlin: the project's own compiler is the truth — the oracle walks up to the gradle root, picks the module task (`:modules:daemon:compileKotlin`), runs it offline and quotes the `e:` lines: the unresolved reference, the syntax error, named with line and column.

Haskell: `ghc -fno-code` on the file, `error:` lines quoted.

Nushell: the hook is Nushell itself — one script, a table of legs, one voice that speaks and one count file that remembers. The snag it survived: a gradle project root twelve directories up, a count file whose rows fused because `save -a` appends no newline — both measured, both fixed in the same hour.

## 4 · In your system

1. The oracle: `Scripts/scripts/hooks/oracle-compile.nu` — PostToolUse, the two legs, the caps, the cooldown.
2. The count: `~/.zcode/hooks/state/oracles.tsv` — spoke · clean · timeout · error, beside `denials.tsv`.
3. The guide's widening: `Scripts/scripts/hooks/rag-guard.nu` now injects every `*-kb/notes/` — kotlin-kb, haskell-kb, theory-kb included (the old list named only nushell-kb).
4. The design moment: `Scripts/scripts/hooks/design-guard.nu` covers `.hs`, and for a Haskell module being born it queries the law notes live — top hits in five seconds, fail-open.

## 6 · Drill

Plant a broken module in a real project and watch the oracle speak:

```nu
'package dev.lattenero.bot.daemon
class Scratch {
    val x: String = neverDeclared()
}' | save -f ~/Projects/zcode-bot-kotlin/modules/daemon/src/main/kotlin/dev/lattenero/bot/daemon/Scratch.kt
'{tool_name: "Write", tool_input: {file_path: "~/Projects/zcode-bot-kotlin/modules/daemon/src/main/kotlin/dev/lattenero/bot/daemon/Scratch.kt"}}' | save -f /tmp/o.json
open --raw /tmp/o.json | ^nu --stdin ~/Scripts/scripts/hooks/oracle-compile.nu
rm ~/Projects/zcode-bot-kotlin/modules/daemon/src/main/kotlin/dev/lattenero/bot/daemon/Scratch.kt
```

Green when the hook answers with `does not compile` and the `Unresolved reference` line. The failing case it rules out: a hook that claims to verify but never runs the compiler — the note exists only when the compiler spoke.
