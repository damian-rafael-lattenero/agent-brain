# C4 · The memory lifecycle

**Denotes.** A memory's state is a pure function of its own row: one decay family, two clocks, and forgetting that excludes but never deletes.

## 1 · The aha

There is no stored state machine to wander. Read the row, compute the state: the freshness clock runs from creation, the usefulness clock runs from the last time anybody needed it — and the floors are exact powers of two, so every boundary is exact in floating point.

## 2 · What it denotes

`lifeWeight = salience × decay(ageSinceLastAccess, halfLifeDays)`. At or above `COOLING_FLOOR` the memory is `ACTIVE`; at or above `FORGET_FLOOR` it is `COOLING`; below, `ARCHIVED`. A salience-1.0 memory nobody touches cools after exactly one half-life and is forgotten after exactly three.

Forgetting is exclusion, not deletion: an archived row leaves both search legs — it cannot fuse, it cannot take a candidate slot — but the row stays, the status buckets count it, and reinforcement resurrects it. Movement is one-way (decay only); a duplicate found later is superseded, not re-extracted.

## 3 · In your languages

Kotlin: `agent-brain/core/src/main/kotlin/dev/lattenero/brain/memory/Lifecycle.kt` — one total classification, no stored machine; its laws (monotonicity, the birth case, exact boundaries, resurrection, one-way movement) are pinned in `LifecycleLawsTest`, and `MemoryStore.SEARCH` is the executable SQL twin pinned equivalent by an integration test.

Nushell: the fleet's bucket counts — the same classification folded from the store — are what the `memory_status` surface reads out.

The difference: Kotlin classifies, Nushell reports the buckets. The snag: two clocks, two meanings — rank freshness reads `created_at`, usefulness reads `last_accessed`; confuse them and a never-read memory looks fresh forever.

## 6 · Drill

Read the fleet's buckets and find the forgotten:

```nu
^docker exec agent-brain-pg psql -U brain -d agent_brain -At -c
"select status, count(*) from memories group by status"
```

Green when three buckets answer and archived is not empty — a fleet with zero archived rows after months is a lifecycle that never runs. The failing case it rules out: a forgetting law that deletes (the row would be gone; here it is only excluded, and the count proves it).
