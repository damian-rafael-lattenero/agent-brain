# B17 · Newtype

**Denotes.** A distinct type with zero runtime cost — the same representation, a different checker-visible identity, so two ids that share a representation still cannot swap.

## 1 · The aha

An alias documents; a newtype PROHIBITS. `typealias TurnId = String` reads well and protects nothing — the swap compiles. The wrapper costs nothing at runtime and buys the checker as the swap's guard.

## 2 · What it denotes

In Haskell: `newtype TurnId = TurnId String` — a distinct type, erased at compile time, with its OWN instance space (the reason newtype exists alongside data: instances without the runtime wrapper).

## 3 · In your languages

**Kotlin.** `@JvmInline value class TurnId(val v: String)` — the checker treats it as a new type and the JVM erases it (zero allocation). The caveats: ONE field, and reflection/serialization see through the erasure. The typealias is the decoy that documents without protecting. Full row: `kotlin-kb/notes/canon-map.md`, `newtype`.

**Nushell.** No compile-time distinctness — the tagged record is the discipline: `{tag: 'turn-id', value: ...}` with wrap/unwrap functions as the only doors, and the census tests policing the kind (the door the language cannot give). Full row: `nushell-kb/notes/canon-map.md`.
