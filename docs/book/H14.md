# H14 · Contravariant functor: a consumer reverses the arrow

**Denotes.** A functor that reverses arrows: `f : b → a` maps to `G f : G a → G b` — which is exactly what a consumer of inputs does, since "a contravariant functor is just a regular functor from the opposite category".

## 1 · The aha

H02's promise has a mirror twin: the producer maps output-side (preserve the shape of what you hand out), the consumer maps input-side (a consumer of `a` becomes a consumer of `b` by putting a `b → a` in front). Same two laws, read in the opposite category.

## 2 · What it denotes

`f : b → a` gives `G f : G a → G b`, with `G id = id` and `G (g ∘ f) = G f ∘ G g` — composition reversed too. In Haskell: `class Contravariant f where contramap :: (b -> a) -> (f a -> f b)`; the model instance is `newtype Op r a = Op (a -> r)` with `contramap f g = g . f` — "the function `f` inserts itself before ... the contents of `Op`".

Two named consequences: functors of this kind into `Set` "are called 'presheaves'", and one contravariant in one argument, covariant in the other, has its own card (H15).

The approximation: the Typeclassopedia and LYAH have no section on it, and a polymorphic function between two such functors "is not a natural transformation in `Hask`" — though the opposite naturality holds, `contramap f . predToStr = predToStr . contramap f`.

The trap: trying to make the plain function type a functor in its first argument — "with just two functions taking `a` and returning, respectively, `b` and `r`, there is simply no way to build a function taking `b` and returning `r`!" Fix the argument instead: "we can't write `instance Functor Either where`, but we can write `instance Functor (Either a)` where". Full theory: `theory-kb/notes/category-theory/contravariant-functor.md`.

## 3 · In your languages

**Kotlin.** Arrow's `mapLeft` "applies a function when the value represents an error" — a map on the error side of `Either`, variance unstated. The stdlib's comparison types (`Comparator`, predicates) are the consumer shape: a new comparison of `B` from one of `A` is precomposition. Full row: `kotlin-kb/notes/canon-map.md`, `functor`.

**Nushell.** Predicates take the input as it comes: `where` "filter values of an input list based on a condition", `any` "tests if any element of the input fulfills a predicate expression" — consumers, with no variance machinery in the language (no hit across the manual mirrors). Full row: `nushell-kb/notes/canon-map.md`, `functor`.
