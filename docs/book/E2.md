# E2 · The three numbers: first pass, canon, course

**Denotes.** The plan's three numbers, live as eval rows since U22: how often a write clears its oracle on the first attempt (first-pass, per language), how often the Canon comes first (canon-recall), and how the sessions flow (rumbo) — shown by the /learn command.

## 1 · The aha

A learned language is a number, never an impression: ≤ 5% first-try oracle failure, the Canon at rank one, cancellations trending down. The three rows make all three checkable from a phone — the /learn command renders every suite that has a run.

## 2 · What it denotes

`fleet eval-numbers` measures and records: first-pass per tracked language (nu, kt, hs — TypeScript stays out) from the last FULL ISO week's oracle runs, passed = clean runs, gate 0.95; rumbo from the whole sealed cancel log, passed = the turns not cancelled, gate 0.0 until the owner sets the target. The rows POST to the brain's `POST /eval/record` — the count keeps ONE writer — and every definition rides in the row's detail.

The canon number: the retrieval suite (E1's four numbers on the Canon questions), 139/140 at the U22 run. The /learn command renders every suite with a run, one honest row each — the display is pinned by a test with the real rows.
