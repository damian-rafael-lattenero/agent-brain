# A0.1 · API, port, socket

**Denotes.** Three nested layers make a program reachable: the socket is the pipe, the port is the number on the door, and the API is the agreed list of things you may say.

## 1 · The aha

A socket carries bytes. A port gives those bytes an address on one machine. An API fixes what the bytes mean, so two programs that never met can still agree on one call.

## 2 · What it denotes

Stripped of any language: a socket is an endpoint pair the operating system hands out, a port is the 16-bit number that tells many sockets on one host apart, and an API is a contract — names in, shapes out. A protocol is the whole agreement both sides share; an API is one side's half of it.

The three exist because a number alone is not an agreement. The port finds the process; only the contract makes the call meaningful. In Haskell they appear as a file descriptor, a number handed to `Network.Socket`, and a module's exported names — and the third has no check behind it, which is why the third is the one that breaks.

## 3 · In your languages

Kotlin declares the surface: `embeddedServer(Netty, port = 8765)` plus a route per name, so the number and the contract live in one file and a missing route is a visible absence.

Nushell discovers the surface: `http get http://127.0.0.1:8765/health` finds the door by URL and trusts that the answer has the shape you expect.

The difference: Kotlin owns both sides when it hosts, Nushell always owns only one. The snag is that a port which answers is not a promise about the API — another program may hold the number, or the same program may answer a name nobody agreed on.

## 4 · In your system

📍 The brain is several doors on one machine. The HTTP surface listens on `127.0.0.1:8765`, and every route it serves — from the health check to the query and save doors — is declared in `agent-brain/core/src/main/kotlin/dev/lattenero/brain/http/Server.kt`.

A second, narrower process answers on `127.0.0.1:8767` behind a bearer secret; the document that explains why it is a separate process is `agent-brain/docs/mcp.md`.

Postgres, the store under all of it, is the third number: `5433`, from `agent-brain/core/src/main/kotlin/dev/lattenero/brain/config/Config.kt`.

One door is not a number at all. `~/.zcode/daemon-local.sock` is a Unix socket on disk, so a local program finds it by path instead of by port.

## 6 · Drill

Call two doors and tell the two failures apart.

```nu
http get --full http://127.0.0.1:8765/health | get status        # 200, a real answer
http get --full http://127.0.0.1:8766/health | get status        # nobody listens here
```

Green when the first prints `200` and the second raises a connection error. If both fail, the brain is not running: a door exists only while a program holds it.
