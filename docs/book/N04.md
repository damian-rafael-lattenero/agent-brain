# N04 · `algebra.nu` — monoids the shell can fold

**Denotes.** Semigroup and Monoid as operation dictionaries — a record `{empty, combine}` — so ONE fold serves every combining case.

## 1 · The aha

Nushell has no typeclasses either, so the dictionary-passing translation applies: a monoid is a RECORD the caller hands to `fold-map`. Six ready-made dictionaries (`monoid-sum`, `monoid-product`, `monoid-str`, `monoid-list`, `monoid-any`, `monoid-all`) cover the day-to-day combines, and the laws are test-pinned the way kap's LAWS.md pins them.

## 2 · What it denotes

`monoid` (build a dictionary from an identity and an associative combine), `fold-map` (THE Foldable star: map every element into the monoid, then combine — `foldMap g = mconcat . map g`), `mconcat` (fold-map id). Verified: `[1 2 3 4 5] | fold-map id (monoid-sum)` answers `15`; the empty list answers `empty`, not an error — `reduce` without `--fold` is the half-monoid that raises (B14's trap, at the shell).
