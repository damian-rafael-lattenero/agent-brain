# H08 · Kleisli category: effectful composition that looks plain

**Denotes.** The category built on a monad whose arrows are the embellished arrows `a → m b` of a base category, composed through the monad's multiplication — effectful functions compose as if they were plain ones.

## 1 · The aha

B20 put effects at the edges; H08 is the shape that lets them chain anyway: `f : a → m b` and `g : b → m c` compose through `>=>` to `a → m c`, with `return` as identity — a category in every sense, so all the discipline of H01 applies to embellished arrows.

## 2 · What it denotes

Objects of the base category; arrows `a → m b`; identity `η_a : a → m a`; composition `f >=> g` threading the wrapped value through. The Typeclassopedia states it flatly: the monad laws "say precisely that functions of type `a -> m b` are the arrows of a category with `(>=>)` as composition" — the Kleisli category of the monad, with `newtype Kleisli m a b = Kleisli { runKleisli :: a -> m b }` as the `Category` instance.

The construction needs a monad — "not every functor, though, gives rise to a Kleisli category" — and the laws are not compiler-checked. The trap is plain composition on embellished arrows: "we cannot use `Function1.compose` ... the output type of `parse` is `Option[Int]` whereas the input type of `reciprocal` is `Int`" — the composite must thread the wrapped value, which is what `>=>` does and `.` cannot. Full theory: `theory-kb/notes/category-theory/kleisli-category.md`.

## 3 · In your languages

**Kotlin.** Arrow's `Raise` DSL is the composition in its own clothes: inside an `either` block, "if at some point we `bind()` a `Left` or find a `raise`, we stop and return that value; if we get to the end, we wrap the result in `Right`" — sequential embellished arrows, one thread. kap's `recover` and the error `Channel` carry the same shape law-first. Full row: `kotlin-kb/notes/canon-map.md`, `monad`.

**Nushell.** `try { } catch { }` — "try to run a block, if it fails optionally run a catch closure" — and `do --capture-errors`: "catch errors as the closure runs, and return them". The composition is statement sequencing; the embellishment is the error value the catch sees. No documented instance beyond that: the honest ceiling, and the reason `nushell-fp/mods/types.nu` exists. Full row: `nushell-kb/notes/canon-map.md`, `monad`.
