# B21 · Total functions

**Denotes.** A total function answers for EVERY input of its type — the answer may be a degraded value, but it is always a value, never an exception and never silence. The measured #2 violated concept in the fleet's Kotlin tests.

## 1 · The aha

`!!` is a promise that some input never happens. It compiles the same as any other line, so the promise is invisible — until one row makes it a bare NPE that names nothing. The total shape spends one extra line so the failure says which row broke the promise.

## 2 · What it denotes

In Haskell, partiality is visible: `head []` crashes with a pattern-match failure, and GHC's `-Wall` flags every incomplete clause. The total head is `safeHead :: [a] -> Maybe a` — the empty case is a CONSTRUCTOR in the type, not a crash. The type then documents the two landings.

Partiality that hides in the type (`!!` is typed `T`, not `T!`) is the Kotlin gap: the signature cannot warn you, so review and the mechanical checks carry it.

## 3 · In your languages

**Kotlin.** Three named shapes carry the law: `?: return` at the edge, `requireNotNull(x) { "context: $x" }` when the invariant is real (it throws — honestly, with a message), `assertNotNull(x)` in a test before the use, so the smart-cast and the failure both name the row. And the measured one: an expression-bodied `@Test` without `: Unit` can infer a nullable tail, and a not-void JUnit method is silently SKIPPED — the suite stays green with a test missing. Full row: `kotlin-kb/notes/canon-map.md`, `total-functions`.

**Nushell.** The total reader: `get -o` + `default`, a shape check before a read (`from json` on garbage returns the string itself, and `describe` answers with the detailed shape — prefix-match it), `complete` at every external edge. The dispatch `match` with a missing arm returns nothing SILENTLY — the census tests are the only coverage proof. Full row: `nushell-kb/notes/canon-map.md`.
