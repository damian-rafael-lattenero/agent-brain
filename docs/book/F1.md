# F1 · The laws, with their receipts

**Denotes.** Every law in this fleet carries its receipt: the command, the number, the row — Done is never a feeling, it is the battery green with the proof beside it.

## 1 · The aha

The difference between an honest fleet and a hopeful one is one habit: when someone says "done", someone can run one command and see it. The receipt is that command, kept beside the law it proves — and a skipped step is said, not hidden.

## 2 · What it denotes

The law file states it twice: "Honest over comfortable: receipts, never cheerleading" and "Done = the battery is green, with the receipt". The receipt's shapes in this fleet: the drill's checkpoint line, the eval row (E3's ledger), the deny line in the count file, the suite verdict, the measured number beside its definition.

What receipts are NOT: cheerleading, inflated status, a green that says nothing was measured. A skipped step is said; a failed test is shown with its output; a claim without its command is a draft, not a close. The /learn command shows the habit from the phone: every row it renders is a receipt someone can re-run.
