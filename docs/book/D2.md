# D2 · Hook: what it is, when it runs, what it can do

**Denotes.** A script the harness runs at a named moment — before a tool, after a write, at the end of a turn — whose exit code and stdout decide what happens next: refuse, advise, or stay silent.

## 1 · The aha

A hook is the only code the harness itself obeys. PreToolUse reading exit 2 refuses the action; PostToolUse cannot refuse — it answers after the fact with context. The determinism is the whole point: the same input, the same answer, no model in the loop.

## 2 · What it denotes

The moments: PreToolUse (before the harness runs a tool), PostToolUse (after a file lands), Stop (at turn end). The contract: the payload rides stdin as JSON, the exit code rules, stdout rides back as context. The deny is a pure predicate over the payload: same payload, same answer, always — and the deny never depends on the count file: with the log unwritable, the hook still exits 2 with the same reason.

The fleet's deny rows are DATA — `DenyRule` records with when-closures, walked first-match-wins — so a new rule is a row, not new code. Advisories teach without refusing: the sleep-sync warn fires, the turn goes on.

## 3 · In your languages

**Kotlin.** The same shape on the bot's side is a sealed interface over replies — the channel classifies, the daemon transports, each leg degrades alone. Full row: `kotlin-kb/notes/canon-map.md`, `maybe-either`.

**Nushell.** The hooks ARE Nushell: typed scripts, one `def main` reading `$in | from json`, exit codes for rulings. `nushell-law.nu` walks its rule table and answers in microseconds. Full row: `nushell-kb/notes/canon-map.md`, `maybe-either`.

- `~/Scripts/scripts/hooks/nushell-law.nu` — the Bash deny table, 15 rows plus the warn path.

## 6 · Drill

Fire a deny for real, the test's own way:

```nu
{tool_name: 'Bash', tool_input: {command: 'echo hi'}} | to json -r
| ^nu --stdin ~/Scripts/scripts/hooks/nushell-law.nu; print $env.LAST_EXIT_CODE
```

Swap the command for `sleep 15sec; print 1` (built by parts) and watch the exit become 2 with its reason.
