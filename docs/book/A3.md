# A3 · The story in two pages

**Denotes.** One message from your phone to the store and back, where every step names the file that does it, so the map stops being a diagram and becomes a route you can walk.

## 1 · The aha

A message never travels as a whole. It becomes a prompt, then a turn, then a line on the wire, then rows — and every hand-off is a file you can open.

## 2 · What it denotes

The trip has three parts: the door (phone to bot), the work (a model with its hands and its store), and the record (what survives as memory). A turn is one exchange with an id; a session is the run of turns that share one context. The id is what lets a record be joined back to the thing it recorded.

In Haskell the trip is a pipeline with two effects in the middle: a `Reader` for the context the turn was given, and a `Writer` for the record it leaves behind.

## 3 · In your languages

Kotlin: the brain's end of the trip is a route that takes a question and returns passages with their sources, and the answer has a declared shape — nothing on that side is untyped.

Nushell: from outside, the same trip is a few calls — save a memory, query the store, read the recent rows — and `hit-rows` in `Scripts/lib/brain.nu` turns the answer into a table.

The difference: the store side is typed and the shell side is a table. The snag: the bot in the middle is Python, so the one hop without a declared shape is the hop that joins the two — its client turns a non-200 into `BrainUnavailable` instead of a silent empty answer.

## 4 · In your system

The trip, step by step:

1. The phone sends to Telegram; the bot receives it by long polling (`bot/src/zcode_bot/poller.py`) or by webhook on `127.0.0.1:8443` (`bot/src/zcode_bot/webhook_server.py`).
2. The daemon prepares the turn and pulls a memory preamble first: `bot/src/zcode_bot/workers.py` asks for it before the turn starts.
3. That call is `bot/src/zcode_bot/brain_client.py`, posting to the search door on 8765 and returning rows with their ids — or nothing, when the brain is down.
4. The turn runs in ZCode; inside it the agent asks the store through the MCP door, `agent-brain/docs/mcp.md`, where the `rag_query` call is a facade over the same loopback call.
5. The store answers: `agent-brain/core/src/main/kotlin/dev/lattenero/brain/rag/RagService.kt` looks the question up in Postgres and returns passages with their uri, title and heading, from `agent-brain/core/src/main/sqldelight/dev/lattenero/brain/db/sq/Rag.sq`.
6. The reply goes back to the phone: `bot/src/zcode_bot/telegram/client.py` sends it as one message.
7. The turn is recorded: the bot's taps append `turn.completed` to `~/.zcode/agent-brain/bus-events.jsonl`, through `bot/src/zcode_bot/hooks.py`.

Where the turn becomes a memory:

8. The brain tails that file (`agent-brain/core/src/main/kotlin/dev/lattenero/brain/bus/FileTailer.kt`) and inserts the line by id, so a replay changes nothing.
9. `agent-brain/core/src/main/kotlin/dev/lattenero/brain/memory/MemoryWorker.kt` finds the completion still unprocessed and hands it to `agent-brain/core/src/main/kotlin/dev/lattenero/brain/memory/MemoryExtractor.kt`, which asks a model for the durable rows; `agent-brain/core/src/main/sqldelight/dev/lattenero/brain/db/sq/Memories.sq` stores them, keyed to the event that produced them.

## 6 · Drill

Walk the record end: take the newest completed turns and check that memory rows point at their ids.

```nu
^docker exec agent-brain-pg psql -U brain -d agent_brain -Atc "select count(*) filter (where source_event_id is null) as untraced, count(*) filter (where source_event_id is not null and source_event_id not in (select id from bus_events)) as orphaned from memories"
^docker exec agent-brain-pg psql -U brain -d agent_brain -Atc "select count(*) from memories where source_event_id is not null"
```

Green when `orphaned` is 0 and the traced count is positive. The failing case it rules out: a memory that points at an event which is not there — a fact no exchange can explain. The `untraced` number is the rows written by hand through the save door, not derived from any turn: they are allowed, and they should be the only ones.
