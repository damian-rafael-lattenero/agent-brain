# D5 · Gate and verdict: allow, guide, ask, block

**Denotes.** A gate reads one action and answers with one of four verdicts — the answer is a value the runtime dispatches on, and a denying gate cites one unambiguous pattern, never a judgement call.

## 1 · The aha

A gate is a predicate with a shaped answer. It does not decide what happens next; it returns `allow`, `guide` (a note rides along), `ask` (one question to you), or `block` (a refusal with its reason), and the caller dispatches on that tag.

The law that keeps it honest: a gate that denies is deterministic. One pattern, written down, self-tested — never "this looks wrong to me".

## 2 · What it denotes

`gate : Action -> Verdict`, with `Verdict = Allow | Guide Note | Ask Question | Block Reason`. Each constructor carries exactly what the next step needs: a note for guide, a question for ask, a reason for block, nothing for allow.

Because the verdict is a value, gates compose: several gates can read one action, their verdicts fold into the strongest one, and the caller stays a table of rows — predicate first, payload second.

## 3 · In your languages

Nushell: a gate is a hook script — read the payload from stdin, check one mechanical shape, answer on the exit. `Scripts/scripts/hooks/english-law.nu` guides (a warning, exit 0); `Scripts/scripts/hooks/write-guard.nu` blocks (the write refuses when the file was never read); `Scripts/scripts/hooks/nushell-typing.nu` blocks defs without a signature.

Kotlin: the same verdict inside the store — `agent-brain/core/src/main/kotlin/dev/lattenero/brain/rag/English.kt` refuses prose that is not English at the door of the index. Block with a reason, deterministically, by one measured pattern.

The difference: Nushell gates speak to the agent mid-flight; Kotlin gates speak at the boundary of the store. The snag: a gate with two exit paths (warn and deny) must say which one fired — the warning that stays silent is a lie.

## 6 · Drill

Make the English gate speak, then go silent.

```nu
{tool_name: 'Edit', tool_input: {file_path: '/tmp/x.md', new_string: '# el resumen del sistema'}}
| to json | ^nu ~/Scripts/scripts/hooks/english-law.nu
{tool_name: 'Edit', tool_input: {file_path: '/tmp/x.md', new_string: '# the system summary'}}
| to json | ^nu ~/Scripts/scripts/hooks/english-law.nu
```

Green when the first payload prints a warning and exits 0 (guide) and the second prints nothing. The failing case it rules out: a gate that reads the action but cannot answer for it — the shape of the payload is part of the gate's contract.
