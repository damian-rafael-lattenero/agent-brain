# A0.4 · Prompt, model, token

**Denotes.** A model answers the text you hand it, one token at a time, inside a fixed window; the prompt is that text, and temperature is how much freedom you leave in the choice of the next token.

## 1 · The aha

The prompt is a call written in plain text. The model is a function from text to text with two hidden arguments, a budget and a coin: the budget is the context window, the coin is temperature.

## 2 · What it denotes

A token is the unit a model reads and writes — roughly three quarters of an English word, never a character. The context window is how many tokens the model can hold at once, prompt plus answer. Temperature dials the sampling: at 0 the model takes the most likely next token every time, so the same prompt tends to give the same answer.

In Haskell the shape is `String -> IO String` with two more arguments: a budget and a die. The budget is not advice. Exceed the window and the text is cut, not refused.

## 3 · In your languages

Kotlin: the brain calls one interface, `ChatProvider.completeJson(system, user, schema)`, so the prompt is two strings plus a schema, and the answer comes back with `promptTokens` and `completionTokens` attached.

Nushell: `http post http://127.0.0.1:11434/api/chat` with a model name and a list of messages is the same call without a wrapper — which is exactly why the wrapper exists.

The difference: Kotlin types the answer, Nushell types nothing. The snag: a cut answer still looks like an answer — check why generation ended before you read a single word of it.

## 4 · In your system

📍 `agent-brain/core/src/main/kotlin/dev/lattenero/brain/chat/Providers.kt` sets temperature 0, `num_ctx` 8192 and `num_predict` 2560 for the local model, and its comment is the lesson: a 512-token cap cut the extracted records mid-word, so the cap now covers what the schema itself allows.

The default model is `qwen2.5:1.5b` on `127.0.0.1:11434`, from `agent-brain/core/src/main/kotlin/dev/lattenero/brain/config/Config.kt`. The token counts of each exchange land in a cost table through `agent-brain/core/src/main/kotlin/dev/lattenero/brain/bus/TurnCosts.kt`.

The extractor's prompt is not prose: `agent-brain/core/src/main/kotlin/dev/lattenero/brain/memory/MemoryExtractor.kt` sends a system text plus a schema, and the model must answer inside that schema.

## 6 · Drill

Make a cut happen on purpose, then read the flag that names it.

```nu
http post -t application/json http://127.0.0.1:11434/api/chat {
  model: "qwen2.5:1.5b", stream: false, options: {num_predict: 8},
  messages: [{role: "user", content: "list ten prime numbers"}]
} | select done_reason message
```

Green when `done_reason` says `length` and the text stops mid-list. Then raise `num_predict` to 200: the same call says `stop`. The failing case it rules out: reading the cut text as if it were the whole answer.

## 7 · Retrieval questions

## Minimum path

- **The aha**: a prompt is text, a model is that function, a token is its unit, the window is its budget.
- **The signature**: `model(prompt, window, temperature)`.
- **The checkpoint**: the capped call answers `length` and the wider one answers `stop`.
