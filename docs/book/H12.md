# H12 · Yoneda: a type is what you can do with it

**Denotes.** Natural transformations from a hom-functor `C(a, −)` to a functor `F` are in one-to-one correspondence with the elements of `F a` — an object is fixed by everything that can be done to it.

## 1 · The aha

A parametric function is far more constrained than it looks: `forall x. (a -> x) -> F x` has exactly as many inhabitants as `F a` has elements — pick the value at the identity and every other component is forced. B19's free theorems are this lemma in everyday clothes.

## 2 · What it denotes

`Nat(C(a, −), F) ≅ F a`: a transformation `α` is determined by `α_a(id_a)` — "completely determined by specifying the value of its single component at just one point"; an element of `F a` travels along every arrow `f : a → x` by `F f`, giving `α_x(f) = F f (α_a(id_a))`.

In Haskell: `forall x. (a -> x) -> F x ≅ F a` — `alpha id :: F a` and `alpha h = fmap h fa` — and the embedding form `forall x. (a -> x) -> (b -> x) ≅ b -> a`.

The approximation: the isomorphism holds for parametric polymorphism — "as usual, `forall` is optional, but I like to write it explicitly to emphasize parametric polymorphism" — and the compiler does not check it; the mirrored manuals have no text on it at all.

The trap: a polymorphic function "can do anything with its argument" is wrong — it can only use what it already holds: `alpha :: Reader () a -> Maybe a` has just two inhabitants, "these correspond to the two elements of the `Maybe ()` type". Callbacks and continuation passing style are "the simplest application of the Yoneda lemma to the identity functor": `forall r. (a -> r) -> r ≅ a` — common in UIs, async and concurrent code, with the drawback of inversion of control. Full theory: `theory-kb/notes/category-theory/yoneda.md`.

## 3 · In your languages

**Kotlin.** No documented instance in the pages read; Arrow's wrapper list (`Option`, `Result`, `Either`, `Ior`) is the vocabulary it offers instead. The everyday echo is the callback: a function handed to code that calls it later, as in B19's drills. Full row: `kotlin-kb/notes/canon-map.md`, `parametricity`.

**Nushell.** `collect` hands the whole stream to one closure — "collect a stream into a value" — `[1 2 3] | collect {|x| $x.1 }` gives `2`: the consumer decides what the stream becomes, the shape documented and no law attached. Full row: `nushell-kb/notes/canon-map.md`, `parametricity`.
